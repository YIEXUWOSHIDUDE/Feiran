# Feiran · 斐然

> What oft was thought, but ne’er so well express’d.

[English](README.md) | 简体中文

一个 AI 驱动的简历工作台，帮助你把真实经历整理成表达清晰、贴合岗位的简历。理解岗位要求，优化经历的呈现方式，并在导出前逐项审核。

![Feiran 斐然 — 真实经历，清晰表达，更明亮的下一步](web/feiran-brand.png)

## 真实经历，清晰表达，更明亮的下一步

- **理解岗位**：提取岗位描述中的要求，核对遗漏和误判。
- **呈现相关经历**：依据已确认的事实，为每个岗位准备简历。
- **调整措辞与结构**：查看 AI 对表达、排序和取舍的建议。
- **保留决定权**：逐项检查修改，单独撤销，并批准你选定的具体版本。
- **导出简历**：审核批准后，下载最终 PDF。

*还是你，表达更出彩。*

## 当前状态

Feiran 的单用户云端工作台已部署到 AWS，提供公网 HTTPS 地址，登录后可用。**目前仅供所有者使用，不提供公开演示或开放注册。** 本地运行仍是可选方式。已在 AWS 验证登录保护、合成中英文简历 PDF 导出、测试容器重建后的数据保留和备份恢复。云端 DeepSeek 密钥已接通，一次受限真实 API 调用已通过；完整简历的生成质量仍需本人审核。参见 [AWS 公网部署](docs/aws-public.md)与[验收记录](docs/aws-acceptance.md)，其中列明已验证范围和剩余检查。

## 如何使用

获得可用工作台的访问权限后：

1. **导入经历。** 上传 PDF 时选择中文或英文，两份简历分别保留。核对后确认经历事实；直接编辑事实会保存为待确认的新版本。
2. **选择岗位。** 在“我的岗位 → 新增岗位”输入任意公开岗位 URL，点击“读取并生成”。Greenhouse、Lever、Ashby 和腾讯链接使用公开接口；其他网站读取网页，优先提取 JobPosting 结构化数据。系统读取标题和正文后准备待审核简历，请核对提取是否完整。登录、验证码、仅由 JavaScript 加载正文或内容不完整的页面可能需要手动粘贴。重复输入已保存的链接会打开已有岗位，也可以浏览关注公司的岗位。
3. **审核岗位简历。** 核对岗位要求、措辞和布局调整，查看简历支持了哪些要求、遗漏了哪些已有依据、还有哪些信息不足。补充建议只有确实符合你的经历时才加入。
4. **批准并导出。** 阅读简历和每项修改，批准这一版后下载最终 PDF。内容改变后，需要重新审核。

在页面顶部切换 **简体中文** 或 **English**，界面会记住你的选择。切换界面语言不会翻译岗位描述、经历事实或简历；可生成的简历语言取决于你的资料。

每个岗位可以单独选择已上传的中文或英文简历。重新上传只替换所选语言，旧资料保留在历史中；相关资料或事实更新后，旧稿仍可预览，但需重新准备和审核才能导出。PDF 需有可提取的文字，暂不支持扫描件识字。

中国与其他地区的岗位使用同一个岗位库，可按中国大陆、其他地区或地点未知筛选，地区依据明确的工作地点判断。除上述招聘板外，也支持添加腾讯招聘官网 `https://careers.tencent.com/zh-cn/search.html`：列表保存职责摘要，选择岗位时重新读取完整要求。BOSS、字节、阿里暂未接入自动刷新，可手动粘贴完整描述。缓存仅代表获取时的公开信息，申请前仍需核对官网状态。

## 你的信息，由你决定

- 经历和已保存材料位于 Feiran 实例的私有数据目录。使用云端工作台时，数据保存在云主机；本地运行时，数据保存在自己的电脑。
- AI 功能会向 DeepSeek 发送相关岗位和经历文字。应用过滤已知身份信息，并用临时编号引用经历。过滤不保证匿名，经历文字本身仍可能识别个人。
- 建议不等于事实。是否属实、采用哪种表达、批准哪个版本，由你决定。
- 批准绑定你看过的具体版本。内容或相关事实改变后，可能需要重新审核批准。

## 当前限制

AI 可能误解岗位要求，也可能改变一句话的含义。自动检查能发现部分无依据的改动，但不能核实你的现实经历，也不能代替人工审核。

岗位排序依据技能词重合，不代表申请资格或录取概率。缺少证据不等于你不具备某项能力；保存的岗位描述也不能证明岗位目前仍开放。

Feiran 用于准备和审核材料，不会提交申请、跟踪投递或预测录用结果。可选语义复核仍处于未经效果验证的实验阶段，不属于常规网页流程。
