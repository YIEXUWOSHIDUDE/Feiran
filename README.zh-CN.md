# Feiran · 斐然

> What oft was thought, but ne’er so well express’d.

[English](README.md) | 简体中文

一个 AI 驱动的简历工作台，帮助你把真实经历整理成表达清晰、贴合岗位的简历。理解岗位要求，优化经历的呈现方式，并在导出前逐项审核。

![Feiran 斐然 — 真实经历，清晰表达，更明亮的下一步](web/feiran-brand.png)

## 真实经历，清晰表达，更明亮的下一步

- **理解岗位**：提取岗位描述中的要求，核对遗漏和误判。
- **呈现相关经历**：依据已确认的事实，为每个岗位准备简历。
- **调整措辞与结构**：查看 AI 对表达、排序和取舍的建议。
- **保留决定权**：逐项检查修改，单独撤销，并批准你选定的具体版本。
- **导出简历**：审核批准后，下载最终 PDF。

*还是你，表达更出彩。*

## 当前状态

Feiran 正在准备以浏览器中的云端工作台提供服务。**目前尚未上线**，没有公开演示、可直接使用的云端网址或开放注册。已准备的部署方案是单用户私有测试版，仍需完成部署和云端验收。

## 如何使用

获得可用工作台的访问权限后：

1. **导入经历。** 上传 PDF 简历，核对提取的信息，确认你希望 Feiran 使用的经历事实。
2. **选择岗位。** 浏览你关注公司的岗位，或粘贴岗位描述。支持 Greenhouse、Lever、Ashby 的公开招聘板；其他来源也可以手动粘贴。
3. **审核岗位简历。** 核对岗位要求、措辞和布局调整，查看简历支持了哪些要求、遗漏了哪些已有依据、还有哪些信息不足。补充建议只有确实符合你的经历时才加入。
4. **批准并导出。** 阅读简历和每项修改，批准这一版后下载最终 PDF。内容改变后，需要重新审核。

在页面顶部切换 **简体中文** 或 **English**，界面会记住你的选择。切换界面语言不会翻译岗位描述、经历事实或简历；可生成的简历语言取决于你的资料。

## 你的信息，由你决定

- 经历和已保存材料位于 Feiran 实例的私有数据目录。使用云端工作台时，数据保存在云主机；本地运行时，数据保存在自己的电脑。
- AI 功能会向 DeepSeek 发送相关岗位和经历文字。应用过滤已知身份信息，并用临时编号引用经历。过滤不保证匿名，经历文字本身仍可能识别个人。
- 建议不等于事实。是否属实、采用哪种表达、批准哪个版本，由你决定。
- 批准绑定你看过的具体版本。内容或相关事实改变后，可能需要重新审核批准。

## 当前限制

AI 可能误解岗位要求，也可能改变一句话的含义。自动检查能发现部分无依据的改动，但不能核实你的现实经历，也不能代替人工审核。

岗位排序依据技能词重合，不代表申请资格或录取概率。缺少证据不等于你不具备某项能力；保存的岗位描述也不能证明岗位目前仍开放。

Feiran 用于准备和审核材料，不会提交申请、跟踪投递或预测录用结果。可选语义复核仍处于未经效果验证的实验阶段，不属于常规网页流程。
